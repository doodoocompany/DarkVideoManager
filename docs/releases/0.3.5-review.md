두 PR의 원본 커밋에서 Linux 미디어 빌드와 Windows 애플리케이션 검사가 모두 성공했습니다. 반점 별점은 저장·조회·통계에서 반올림하지 않으며 재생 횟수의 정수 검사는 유지합니다. 원본 파일이 없으면 변환이나 외부 플레이어 실행 전에 파일 위치·드라이브 연결을 안내합니다.

Ollama는 연결 5초, 데이터가 오지 않는 대기 120초, 한 시도 전체 300초로 제한하며 최대 세 번 시도합니다. 응답 조각을 받더라도 완료 표시와 내용 검사를 통과해야 저장합니다. 로컬 HTTP 시험 서버의 느린 응답·중단·무한 응답, UTF-8 경계, 종료·재개와 기존 자막·설치·Vulkan을 포함한 WSL Python 검사 151개를 통과했습니다. 실제 제보자의 PC, 모든 GPU·언어·장시간 영상이나 번역 품질을 검증한 것은 아닙니다.

배포 버전은 0.3.5이며 설치형·포터블, 자동 업데이트 정보·blockmap, 앱 소스와 미디어 대응 소스를 함께 제공합니다. 통합 검사와 실제 패키지의 최종 결과·해시·검증 범위는 릴리스의 [VERIFICATION.md](https://github.com/doodoocompany/DarkVideoManager/releases/download/v0.3.5/VERIFICATION.md)와 [SHA256SUMS.txt](https://github.com/doodoocompany/DarkVideoManager/releases/download/v0.3.5/SHA256SUMS.txt)에 기록합니다.
